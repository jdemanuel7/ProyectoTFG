# 🏀 NBA Stats & News Web – Trabajo de Fin de Grado

Este proyecto es una aplicación web desarrollada como Trabajo de Fin de Grado (TFG), cuyo objetivo es ofrecer una plataforma dinámica y accesible para los aficionados al baloncesto, especialmente a la NBA. La web permite consultar estadísticas actualizadas, acceder a enlaces para ver partidos en directo o en diferido, y mantenerse informado con las últimas noticias de la liga.

---

## 🌐 Funcionalidades principales

- 📊 **Consulta de estadísticas**: Visualización de estadísticas individuales por jugador y por equipo, incluyendo puntos, rebotes, asistencias, porcentajes de tiro, entre otros.
- 🎥 **Acceso a enlaces de partidos**: Enlaces verificados para ver los partidos en directo o resúmenes de encuentros anteriores.
- 📰 **Últimas noticias**: Sección dedicada a noticias actualizadas sobre equipos, jugadores, traspasos y sucesos relevantes de la temporada.
- 🔍 **Búsqueda avanzada**: Posibilidad de buscar por jugador, equipo o palabra clave.
